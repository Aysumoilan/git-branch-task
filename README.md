
Bu layihə Git və GitHub-da branching, dəyişiklikləri merge və repository idarəetməsini təcrübədən keçirmək üçün hazırlanıb.

* **main**: Tam hazır və stabil kodlar.
* **staging**: Birləşdirmədən öncəki sınaq mühiti.
* **develop**: Əsas inkişaf sahəsi.
* **feature/html-page**: HTML faylı üzərində işlər üçün.
* **feature/python-script**: Python skripti üzərində işlər üçün.

- Budaq hiyerarşiyasını qurduq (`main` -> `staging` -> `develop`).
- Lokal və distant (remote) feature budaqları yaradıb kodlarımızı yenilədik.
- Bütün dəyişiklikləri `develop` -> `staging` -> `main` zənciri ilə birləşdirdik.
- `git fetch` və `git pull` əməliyyatlarının fərqini praktiki olaraq yoxladıq.# git-branch-task
